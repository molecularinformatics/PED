# Inspect the impact of SMILES representations on pretrained embeddings

We ablated different types of SMILES and use them as input for pretrained models to generate embeddings:

- Raw SMILES
- Canonical SMILES
- Canonical SMILES with shuffled atom order
- Same canonical SMILES with conformers generated by different random seeds

Run script by using:

```python
python canonical_shuffle_test/shuffle_distance.py --run_geodiff --run_molformer
```
